# BitNode Website

Static official website for BitNode, a Hong Kong mobile programmatic advertising platform.

## Preview

Open `index.html` in a browser.

## Customize Before Launch

- Replace `partnerships@bitnode.hk` with the real receiving email if needed.
- Connect the contact form to a backend, CRM, or form service for production lead capture.
- Update legal pages, privacy policy, and company registration details before running paid acquisition traffic.

## Deploy

This is a single-file static website. It can be deployed to Cloudflare Pages, GitHub Pages, Netlify, Vercel, object storage, or any standard web server.
